# Capstone 1 — Data Storytelling, Excel & SQL

For this project, I will be assembling, shaping, and analyzing sample sales data for EmporiUm, a fictional student bookstore chain that also sells technology products, art supplies, and other merchandise both in-store and online.

I will use SQL to read and analyze the sales data, extract useful information, and use Excel to create visualizations that help present the results of my analysis.
